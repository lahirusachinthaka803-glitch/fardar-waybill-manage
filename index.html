API Notes

  • Existing Waybill endpoint from your Fardar documentation is used for the POST sync.
  • Fardar Existing Waybill API codes 200–214 are treated as API/result codes, not parcel-delivery statuses. 200 means the parcel was successfully inserted; 201–214 are validation/API error or status messages. The parcel delivery status changes only when Fardar returns current_status.
  • If a response contains current_status, that value is mapped to our WAITING/DISPATCHED/DELIVERED/RETURNED categories.
  • The Fardar Reverse API documentation you provided returns waybill_id, current_status and last_update_time. This page reads those callbacks from ./reverse_api.php every 30 seconds.
  • amount is no longer entered manually. It is imported from the account's Excel file and included in account/all-account summaries.
  • Each account has its own Excel upload. Matching Account + Waybill updates the existing parcel rather than creating a duplicate.
